# Security

## Reporting a security problem

Please email team@digitalhabits.org rather than opening a public issue. Describe the issue, how to reproduce it, and which version of Digital Habits: Phone-Free 2FA you use and in which browser. Never include a real two-factor secret or backup in a report. We reply within three days, treat security problems as our top priority, and let you know when a fix is released.

## Anything else

Either reach out at team@digitalhabits.org or open an issue at <https://github.com/digitalhabits/phone-free-2fa/issues>.
